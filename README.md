# tamilver

தமிழ்வேர் (TamilVer) - பழந்தமிழ் சொல் பரிணாம ஆய்வுத்தளம்

வரலாற்றுக் காலங்களில் தமிழ் சொற்களின் பரிணாமத்தை ஆய்வு செய்யும் டிஜிட்டல் மொழியியல் தளம். இலக்கியச் சான்றுகள், பிராமி எழுத்து வடிவம் மற்றும் AI நண்பன் சுவடி வாசிப்பு.

## Features
- **சொல் பரிணாம ஆய்வு (Word Evolution)**: தொல்காப்பியம், சங்க இலக்கியம், இடைக்காலம் முதல் தற்காலம் வரை சொற்களின் வேர்ச்சொல் மற்றும் மாற்றங்கள்.
- **இலக்கியத் திரட்டு (Literary Works)**: சங்க இலக்கியம், அற இலக்கியம், காப்பியங்கள் மற்றும் பக்தி இலக்கியத் தரவுகள்.
- **சுவடி வாசிப்பாளர் (Manuscript AI Reader)**: பழந்தமிழ் ஓலைச்சுவடிகளை வாசித்து நவீன வடிவில் விளக்கும் AI வசதி.
- **பன்மொழி வசதி (Multilingual)**: தமிழ், ஆங்கிலம், இந்தி, தெலுங்கு, மலையாளம், கன்னடம்.

## Development Setup

```bash
# Install dependencies
npm install --legacy-peer-deps

# Run local development server
npm run dev
```

App runs locally on: `http://localhost:3000/`
